# เอกสารมาตรฐานสถานะเครื่องพิมพ์และการแจ้งเตือน (Printer Status & Alert Specification)
**ระบบ:** PrinterStatsNoti  
**เวอร์ชัน:** v1.0.4 ขึ้นไป  
**วันที่ปรับปรุง:** 17 พฤศจิกายน 2026  

---

## 1. บทนำ (Introduction)
ในระบบตรวจจับสถานะเครื่องพิมพ์เดิม ปัญหาของเครื่องพิมพ์จะถูกสรุปเป็นคำว่า **"มีปัญหา" (Error)** เพียงอย่างเดียว ทำให้ผู้ดูแลระบบไม่ทราบว่าเกิดอะไรขึ้น เช่น เป็นเพียงแค่กระดาษหมด หรือมีปัญหากระดาษติด หรือตลับหมึกหมดเกลี้ยง

ระบบได้ทำการยกระดับการถอดรหัสบิตแมป SNMP ตามมาตรฐาน **RFC 2790 (Host Resources MIB)** และ **RFC 3805 (Printer MIB)** ให้ครอบคลุมครบทั้ง **15 สถานะข้อผิดพลาด (15 Error Flags)** พร้อมนำข้อความแจ้งเตือนจริงจากหน้าจอ LCD ของเครื่องพิมพ์ (`prtAlertDescription` และ `prtConsoleDisplayBufferText`) มาแสดงผล และจัดระบบคัดกรองการแจ้งเตือนออกเป็น **3 ระดับความเร่งด่วน (3-Tier Severity)** เพื่อแก้ปัญหาการแจ้งเตือนรบกวน (Notification Fatigue)

---

## 2. ตารางถอดรหัสสถานะ SNMP ทั้ง 15 สถานะ (SNMP Error Flags)
ระบบอ่านบิตแมป 2 ไบต์จาก OID `hrPrinterDetectedErrorState` (`1.3.6.1.2.1.25.3.5.1.2.1`) ดังนี้:

### ไบต์ที่ 0 (Byte 0: Bit 0 – Bit 7)
| บิต (BitMask) | รหัสในระบบ (Flag) | ความหมายในภาษาไทย | ระดับความเร่งด่วน | ค่าเริ่มต้นการส่ง LINE |
| :--- | :--- | :--- | :--- | :--- |
| `0x80` (บิต 0) | `lowPaper` | กระดาษใกล้หมด | Warning (เตือน) | ไม่ส่ง LINE (เฉพาะบนเว็บ) |
| `0x40` (บิต 1) | `noPaper` | **กระดาษหมด (Out of Paper)** | Info (หน้างาน) | **ไม่ส่ง LINE (เฉพาะบนเว็บ)** |
| `0x20` (บิต 2) | `lowToner` | หมึกใกล้หมด (<= เกณฑ์ที่ตั้งไว้) | Warning (เตือน) | ส่ง LINE |
| `0x10` (บิต 3) | `noToner` | **หมึกหมดเกลี้ยง (0%)** | Critical (วิกฤต) | **ส่ง LINE ทันที** |
| `0x08` (บิต 4) | `doorOpen` | ฝาครอบเครื่องพิมพ์เปิดอยู่ | Info (หน้างาน) | ไม่ส่ง LINE (เฉพาะบนเว็บ) |
| `0x04` (บิต 5) | `jammed` | **กระดาษติด (Paper Jam)** | Critical (วิกฤต) | **ส่ง LINE ทันที** |
| `0x02` (บิต 6) | `offline` | เครื่องพิมพ์ออฟไลน์ / ปิดเครื่อง | Warning (เตือน) | ส่ง LINE |
| `0x01` (บิต 7) | `serviceRequested` | เครื่องขัดข้อง / ต้องการเรียกช่างซ่อม | Critical (วิกฤต) | **ส่ง LINE ทันที** |

### ไบต์ที่ 1 (Byte 1: Bit 8 – Bit 14)
| บิต (BitMask) | รหัสในระบบ (Flag) | ความหมายในภาษาไทย | ระดับความเร่งด่วน | ค่าเริ่มต้นการส่ง LINE |
| :--- | :--- | :--- | :--- | :--- |
| `0x80` (บิต 8) | `inputTrayMissing` | ถาดป้อนกระดาษถูกถอดออก/หลุด | Info (หน้างาน) | ไม่ส่ง LINE (เฉพาะบนเว็บ) |
| `0x40` (บิต 9) | `outputTrayMissing` | ถาดรับกระดาษถูกถอดออก/หลุด | Info (หน้างาน) | ไม่ส่ง LINE (เฉพาะบนเว็บ) |
| `0x20` (บิต 10) | `markerSupplyMissing` | ตลับหมึกไม่ได้ถูกติดตั้ง/หลุด | Info (หน้างาน) | ไม่ส่ง LINE (เฉพาะบนเว็บ) |
| `0x10` (บิต 11) | `outputNearFull` | ถาดรับกระดาษใกล้เต็ม | Warning (เตือน) | ไม่ส่ง LINE (เฉพาะบนเว็บ) |
| `0x08` (บิต 12) | `outputFull` | ถาดรับกระดาษเต็ม ไม่สามารถรับงานต่อได้ | Info (หน้างาน) | ไม่ส่ง LINE (เฉพาะบนเว็บ) |
| `0x04` (บิต 13) | `inputTrayEmpty` | ถาดป้อนกระดาษว่างเปล่า | Info (หน้างาน) | ไม่ส่ง LINE (เฉพาะบนเว็บ) |
| `0x02` (บิต 14) | `overduePreventMaint` | ถึงรอบการบำรุงรักษาเชิงป้องกัน (PM) | Warning (เตือน) | ไม่ส่ง LINE (เฉพาะบนเว็บ) |

> **หมายเหตุพิเศษเรื่องการอนุมานสถานะ (Inferred Flags):**  
> เครื่องพิมพ์บางยี่ห้อ (เช่น เครื่องขนาดเล็กหรือบางเฟิร์มแวร์) อาจไม่ได้เซ็ตบิตแมป `hrPrinterDetectedErrorState` เมื่อกระดาษหมดหรือหมึกหมด ระบบจึงมีกลไกตรวจสอบเพิ่มเติมอัตโนมัติ:
> 1. หากระดับถาดกระดาษใน `prtInputCurrentLevel` มีค่าเท่ากับ `0%` ระบบจะอนุมานสถานะ `noPaper` ให้โดยอัตโนมัติ
> 2. หากระดับหมึกใน `prtMarkerSuppliesLevel` มีค่าเท่ากับ `0%` ระบบจะอนุมานสถานะ `noToner` ให้โดยอัตโนมัติ

## 3. สถาปัตยกรรมการจัดลำดับความเร่งด่วน 3 ระดับ (3-Tier Severity)

| ระดับ | วัตถุประสงค์ & พฤติกรรม | ตัวอย่างสถานะ | ช่องทางแจ้งเตือน |
| :--- | :--- | :--- | :--- |
| **1. วิกฤต (Critical)** | งานพิมพ์หยุดชะงัก ผู้ใช้งานหน้างานแก้ไขเองไม่ได้ หรือต้องการการเข้าแทรกแซงทันที | 🚨 **กระดาษติด (jammed)**<br>💧 **หมึกหมดเกลี้ยง (noToner)**<br>🛠️ **เครื่องขัดข้องเรียกช่าง (serviceRequested)** | **ส่ง LINE ทันที** + แสดงแบนเนอร์สีแดงบนหน้าเว็บ |
| **2. แจ้งเตือน (Warning)** | ยังพิมพ์ต่อได้ชั่วคราวแต่ต้องการการวางแผนล่วงหน้า หรือการสื่อสารขัดข้อง | 🔴 **เครื่องออฟไลน์ (offline)**<br>💧 **หมึกใกล้หมด (lowToner)**<br>📋 **สัญญาเช่าใกล้หมดอายุ (contract_expiring)** | **ส่ง LINE** + แสดงแบนเนอร์สีเหลืองบนหน้าเว็บ |
| **3. ประจำหน้างาน (Info / On-site)** | ปัญหาที่ผู้ใช้ที่ยืนอยู่หน้าเครื่องพิมพ์สามารถจัดการได้เองทันที (เช่น เดินไปหยิบกระดาษมาใส่ หรือดันฝาปิดเครื่อง) ไม่มีความจำเป็นต้องส่งแจ้งเตือนผ่านกลุ่ม LINE รบกวนทุกคน | 📄 **กระดาษหมด (noPaper / inputTrayEmpty)**<br>🚪 **ฝาเครื่องเปิดอยู่ (doorOpen)**<br>📥 **ถาดรับกระดาษเต็ม (outputFull)**<br>⚠️ **ถาดกระดาษหลุด (inputTrayMissing)** | **แสดงบนหน้าเว็บเท่านั้น (`web_only`)**<br>*(ไม่ส่ง LINE เว้นแต่ผู้ใช้จะเข้าไปติ๊กเปิด)* |

## 4. การปรับแต่งกฎแจ้งเตือน LINE (Configurable LINE Notify Rules)

ผู้ดูแลระบบสามารถปรับแต่งได้อย่างอิสระผ่านเมนู **"ตั้งค่าระบบ" (Settings Modal)**:

```
[x] 🚨 กระดาษติด (Paper Jam)               -> ค่าเริ่มต้น: ติ๊กถูก (ส่ง LINE)
[x] 💧 หมึกหมดเกลี้ยง (0%)                   -> ค่าเริ่มต้น: ติ๊กถูก (ส่ง LINE)
[x] 🛠️ ฮาร์ดแวร์เสีย / เรียกช่าง             -> ค่าเริ่มต้น: ติ๊กถูก (ส่ง LINE)
[x] 💧 หมึกใกล้หมด                         -> ค่าเริ่มต้น: ติ๊กถูก (ส่ง LINE)
[x] 🔴 เครื่องออฟไลน์ (Offline)             -> ค่าเริ่มต้น: ติ๊กถูก (ส่ง LINE)
[x] 📋 สัญญาใกล้หมดอายุ                    -> ค่าเริ่มต้น: ติ๊กถูก (ส่ง LINE)
[ ] 📄 กระดาษหมด (Out of Paper)            -> ค่าเริ่มต้น: ไม่ติ๊ก (แสดงเฉพาะบนเว็บ)
[ ] 🚪 ฝาเปิด / ถาดกระดาษมีปัญหา           -> ค่าเริ่มต้น: ไม่ติ๊ก (แสดงเฉพาะบนเว็บ)
```

### โครงสร้างข้อมูลใน `store.json`:
```json
{
  "settings": {
    "lineNotifyRules": {
      "paperJam": true,
      "noToner": true,
      "hardwareError": true,
      "lowInk": true,
      "offline": true,
      "contractExpiring": true,
      "noPaper": false,
      "doorOrTray": false
    }
  }
}
```

## 5. การแสดงผลบนแดชบอร์ด (Dashboard UI Improvements)

### 5.1 แผงแจ้งเตือนปัญหาขณะนี้ (Active Issues Panel)
เมื่อมีเครื่องพิมพ์เครื่องใดเครื่องหนึ่งพบปัญหา จะมีแบนเนอร์สีส้ม/แดงปรากฏขึ้นด้านบนของตารางทันที แสดง:
- ชื่อเครื่องพิมพ์, หมายเลข IP, และจุดที่ตั้ง
- ป้ายระบุปัญหาแบบเฉพาะเจาะจง (เช่น `🚨 กระดาษติด`, `📄 กระดาษหมด`)
- ข้อความจากหน้าจอ LCD เครื่องพิมพ์ (หากมี)
- ป้ายระบุช่องทางแจ้งเตือน:
  - `<span class="bg-emerald-100 text-emerald-700">ส่ง LINE</span>` สำหรับปัญหาที่ส่ง LINE
  - `<span class="bg-slate-200 text-slate-600">เฉพาะบนเว็บ</span>` สำหรับปัญหาที่ไม่รบกวนส่ง LINE

### 5.2 ป้ายสถานะแบบฉลาด (Smart Status Badges)
แทนที่คำว่า "มีปัญหา" เดิมด้วยป้ายสถานะที่มีความหมายชัดเจน:
- `🚨 กระดาษติด` (สีแดงเข้ม มีไฟกะพริบ)
- `💧 หมึกหมดเกลี้ยง` (สีแดงเข้ม)
- `🛠️ เรียกช่างบริการ` (สีแดงเข้ม)
- `🔴 ออฟไลน์` (สีเทาเข้ม)
- `📄 กระดาษหมด` (สีเหลืองอำพัน)
- `🚪 ฝาเครื่องเปิด` (สีเหลืองอำพัน)
- `📥 ถาดรับเต็ม` (สีเหลืองอำพัน)
- `💧 หมึกใกล้หมด` (สีเหลืองอำพัน)
- `พร้อมใช้` (สีเขียว)

### 5.3 ประวัติการแจ้งเตือน (Alert History Badge)
ในกล่องประวัติการแจ้งเตือน ระบบแยกสถานะการส่งออกเป็น:
- `ส่ง LINE แล้ว`: ส่งข้อความเข้ากลุ่ม LINE เรียบร้อย
- `เฉพาะบนเว็บ (ไม่ส่ง LINE)`: บันทึกและแสดงผลบนเว็บตามกฎที่ตั้งไว้ เพื่อไม่ให้รบกวนกลุ่ม LINE
- `ยังไม่ตั้งค่า LINE`: เครื่องตรวจพบปัญหาแต่ยังไม่ได้ใส่ Channel Token
- `ล้มเหลว`: ส่งไม่สำเร็จ พร้อมระบุ Error Detail จาก LINE API
