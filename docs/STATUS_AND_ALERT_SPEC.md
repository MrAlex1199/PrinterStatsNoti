# เอกสารมาตรฐานสถานะเครื่องพิมพ์และการแจ้งเตือน (Printer Status & Alert Specification)
**ระบบ:** PrinterStatsNoti  
**เวอร์ชัน:** v1.0.6 ขึ้นไป  
**วันที่ปรับปรุง:** 18 พฤศจิกายน 2026  

---

## 1. บทนำ (Introduction)
จากผลการทดสอบใช้งานจริง (Field Testing) ผู้ใช้งานต้องการระบบที่ **เข้าใจง่าย รวดเร็ว และไม่มีการแจ้งเตือนรบกวน (Zero Noise)**:
1. **ตัดปัญหาที่ผู้ใช้หน้างานจัดการเองได้ออกทั้งหมด:** กระดาษหมด, ถาดกระดาษว่าง, กระดาษต่ำ, ฝาเครื่องเปิดอยู่ เป็นสิ่งที่ผู้ใช้ที่เดินไปสั่งพิมพ์สามารถใส่กระดาษหรือปิดฝาได้เองทันที จึงไม่นำมาเปลี่ยนสถานะเครื่องพิมพ์ให้เป็นสีแดง และไม่ส่งข้อความรบกวนทาง LINE
2. **ตัดสถานะ "เรียกช่างบริการ" (Call Service):** ถอดสถานะเรียกช่างออกเพื่อความเรียบง่าย แสดงเฉพาะสถานะหลักที่ชัดเจนของเครื่องพิมพ์
3. **จัดโครงสร้างแดชบอร์ดแบบ 3 แท็บ (3-Tab Architecture):** แยกหน้าจอออกเป็น 3 แท็บอิสระ ได้แก่ **"แจ้งเตือนสถานะ"**, **"รายการเครื่องพิมพ์"**, และ **"ประวัติ LINE"** เพื่อไม่ให้กล่องแจ้งเตือนดันตารางเครื่องพิมพ์ตกขอบจอ

## 2. สถานะหลักของเครื่องพิมพ์ (Simplified Core Statuses)

ระบบสรุปสถานะเครื่องพิมพ์ออกเป็น 6 สถานะหลักเข้าใจง่าย (+ 1 สถานะสำหรับเครื่องพิมพ์ USB):

| ลำดับความสำคัญ | สถานะที่แสดง | สี/สไตล์ | เงื่อนไขการตรวจจับ | ส่ง LINE? |
| :---: | :--- | :--- | :--- | :---: |
| 1 | 🚨 **กระดาษติด** | พื้นหลังแดงเข้ม ตัวหนังสือแดง | SNMP bitmask `jammed` (0x04) | ใช่ |
| 2 | 💧 **หมึกหมด** | พื้นหลังแดง ตัวหนังสือแดง | SNMP bitmask `noToner` หรือระดับหมึก = 0% | ใช่ |
| 3 | ⚠️ **หมึกใกล้หมด** | พื้นหลังส้ม-เหลือง | ระดับหมึก <= เกณฑ์ที่ตั้งไว้ (ค่าเริ่มต้น 15%) หรือ `lowToner` | ใช่ |
| 4 | 🔴 **ออฟไลน์** | พื้นหลังเทาเข้ม ตัวหนังสือเทา | ไม่สามารถเชื่อมต่อ IP/SNMP ได้ หรือบิต `offline` | ใช่ |
| 5 | 🖨️ **กำลังพิมพ์** | พื้นหลังฟ้า ตัวหนังสือฟ้า | `hrPrinterStatus` มีค่าเท่ากับ 4 (Printing) | ไม่ส่ง |
| 6 | 🟢 **พร้อมใช้** | พื้นหลังเขียวอ่อน ตัวหนังสือเขียว | เครื่องเปิดทำงานปกติ ไม่มีข้อผิดพลาดที่กระทบระบบ | ไม่ส่ง |
| * | 🔌 **USB** | พื้นหลัง Slate | เครื่องพิมพ์ประเภทเชื่อมต่อสาย USB (ไม่ได้ต่อเน็ตเวิร์ก) | ตามสัญญา |

> **หมายเหตุ:** ปัญหากระดาษหมด (`noPaper`), ถาดกระดาษว่าง (`inputTrayEmpty`), หรือฝาเปิด (`doorOpen`) จะ**ไม่ทำให้สถานะเปลี่ยนเป็น Error/Warning** เครื่องพิมพ์จะยังคงแสดงเป็น **"พร้อมใช้" (Online)** ตามปกติ

## 3. สถาปัตยกรรมแดชบอร์ด 3 แท็บ (3-Tab Navigation)

แดชบอร์ดถูกจัดระเบียบใหม่เป็น 3 แท็บ พร้อมตัวเลข Badge แสดงจำนวน:

```
[ ⚠️ แจ้งเตือนสถานะ (1) ]   [ 🖨️ รายการเครื่องพิมพ์ (3) ]   [ 📋 ประวัติ LINE (4) ]
```

1. **แท็บ "แจ้งเตือนสถานะ" (Active Issues Tab):**
   - แสดงการ์ดเครื่องพิมพ์ที่กำลังมีปัญหาสำคัญเท่านั้น (กระดาษติด, หมึกหมด, หมึกใกล้หมด, ออฟไลน์, สัญญาใกล้หมด)
   - หากไม่มีเครื่องใดพบปัญหา จะแสดงหน้าต่างสถานะว่างพร้อมข้อความ *"ระบบปกติ ไม่พบเครื่องพิมพ์ที่มีปัญหาขณะนี้"* พร้อมปุ่มลัดไปยังแท็บรายการเครื่องพิมพ์
   - ระบบจะสลับมาแท็บนี้เป็นค่าเริ่มต้นเมื่อเปิดแอป หากมีเครื่องพิมพ์ที่พบปัญหา
2. **แท็บ "รายการเครื่องพิมพ์" (Printers List Tab):**
   - แสดงรายการเครื่องพิมพ์ทั้งหมด พร้อมเครื่องมือค้นหา, จัดกลุ่มตามยี่ห้อ/ผู้ให้บริการ, การเรียงลำดับ (Sort by), และการสลับมุมมอง การ์ด/ตาราง
   - ตัดหลอดหมึกสีที่ไม่จำเป็นในตารางตามการตั้งค่า ทำให้ตารางกะทัดรัดอ่านง่าย
3. **แท็บ "ประวัติ LINE" (LINE History Tab):**
   - เก็บรวบรวมประวัติการส่งข้อความแจ้งเตือนทาง LINE พร้อมสถานะการจัดส่ง (Sent / Failed / Cooldown)
   - มีปุ่ม *"ส่งรายงานประจำวันทันที"* เพื่อทดสอบหรือสรุปยอดได้ตลอดเวลา

## 4. กฎการแจ้งเตือน LINE ที่ปรับแต่งได้ (Configurable LINE Notify Rules)

ผู้ดูแลระบบสามารถเลือกเปิด/ปิดการส่ง LINE สำหรับปัญหาแต่ละประเภทได้อย่างอิสระผ่านเมนู **"ตั้งค่าระบบ" (Settings Modal)**:

| กฎการแจ้งเตือน | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :---: | :--- |
| **กระดาษติด (Paper Jam)** | ✅ เปิด | มีกระดาษติดค้างในชุดฟีด ต้องเดินไปดึงกระดาษออก |
| **หมึกหมดเกลี้ยง (0%)** | ✅ เปิด | หมึกพิมพ์หมดเกลี้ยง ไม่สามารถพิมพ์งานต่อได้ |
| **หมึกใกล้หมด** | ✅ เปิด | หมึกพิมพ์เหลือต่ำกว่าเกณฑ์ % ที่กำหนดไว้ล่วงหน้า |
| **เครื่องออฟไลน์ (Offline)** | ✅ เปิด | ปิดเครื่องหรือสายแลนหลุด ไม่ตอบสนองเครือข่าย |
| **สัญญาใกล้หมดอายุ** | ✅ เปิด | วันสิ้นสุดสัญญาเช่าเครื่องพิมพ์เหลือตามเกณฑ์ที่กำหนด |

### โครงสร้างข้อมูลใน `store.json`:
```json
{
  "settings": {
    "lineNotifyRules": {
      "paperJam": true,
      "noToner": true,
      "lowInk": true,
      "offline": true,
      "contractExpiring": true
    }
  }
}
```

## 5. การจำลองสถานะ (Simulator Scenarios)

สำหรับทดสอบระบบ มีสถานการณ์จำลอง (Simulator Scenarios) ให้เลือกทดสอบ 4 แบบ:
- `normal`: จำลองสถานะปกติ พร้อมใช้งาน หมึกเต็ม 100%
- `low_ink`: จำลองสถานะหมึกพิมพ์ใกล้หมด (Black 8%)
- `paper_jam`: จำลองสถานะกระดาษติด (Jammed)
- `offline`: จำลองสถานะออฟไลน์ ไม่ตอบสนอง
